# ATM (Console-based)

## Description
This project is a console-based ATM simulator written in Python. It allows users to perform typical ATM transactions such as checking balance, withdrawing funds, depositing funds, and transferring funds between accounts.

## Features
- User authentication with PIN
- Check account balance
- Withdraw cash
- Deposit cash
- Transfer funds between accounts
- View transaction history
